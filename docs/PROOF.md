## 1. Notation

Throughout, $R=\{0=r_0<r_1<\dots<r_k=w\}$, $d=\gcd(r_1,\dots,r_k)$, and $n>0$ with $\gcd(n,d)=1$. For an integer $\lambda\ge 0$ put
$$m=m_\lambda=n+\lambda w,\qquad M=M_\lambda=m+w,\qquad H_\lambda=\langle m+r_0,\dots,m+r_k\rangle .$$
Since $d\mid w$, we have $\gcd(m,d)=\gcd(n,d)=1$.

* For $X\subseteq\mathbb Z$ and $s\in\mathbb N$, $sX$ denotes the set of sums of $s$ elements of $X$, with repetition allowed; $0X=\{0\}$. Because $0\in R$, we have $sR\subseteq (s+1)R$.
* $S=\bigcup_s sR$ is the submonoid of $\mathbb N$ generated by $R$. Put $R'=\{w-r:r\in R\}$, which also contains $0$ and $w$, and $S'=\bigcup_s sR'$. Then $S,S'\subseteq d\mathbb N$. Also $\gcd(R)=d$, and $\gcd(R')=\gcd(w,w-r_1,\dots)=\gcd(w,r_1,\dots,r_k)=d$. So $S/d$ and $S'/d$ are submonoids of $\mathbb N$ with gcd $1$, and hence have finite complement in $\mathbb N$ (standard fact). Fix a nonnegative multiple $c$ of $d$ such that **every multiple of $d$ that is $\ge c$ lies in $S\cap S'$.**
* $\Lambda=\{(a,b)\in(d\mathbb Z)^2:\ a+b\in w\mathbb Z\}$, which is a lattice.
* $T=\{(a,\,sw-a): s\in\mathbb N,\ a\in sR\}$, and $g_i=(r_i,\,w-r_i)$ for $0\le i\le k$.
* $T^*=\{(a,b)\in\Lambda:\ a\in S,\ b\in S'\}$.
* $\pi_\lambda:\Lambda\to\mathbb Z$, $\pi_\lambda(a,b)=(aM+bm)/w$. If $a+b=sw$ then $\pi_\lambda(a,b)=a+sm$, so the value is an integer.
* $v=v_\lambda=(-dm,\ dM)$ and $P=P_\lambda=(0,\ dM)$.
* $\Lambda'=\{(p,q)\in(d\mathbb Z)^2:\ p+q\equiv -dn\pmod w\}$. Since $dM=dn+d(\lambda+1)w\equiv dn\pmod w$, we have $\Lambda'=\Lambda-P_\lambda$ for every $\lambda$. Note that $\Lambda'$ itself does not depend on $\lambda$, and $\Lambda'+\Lambda=\Lambda'$.
* $\chi=\chi_\lambda:\Lambda\to\{0,1\}$, with $\chi(y)=1$ if and only if $\pi_\lambda(y)\in H_\lambda$.
* $\Sigma_\lambda=\{(a,b)\in\Lambda:\ 0\le a<dm\}$ is the canonical strip.
* $[\ \cdot\ ]$ denotes the truth value of a statement, $1$ or $0$.
* $\operatorname{PF}(H)=\{x\in\mathbb Z\setminus H:\ x+h\in H\ \forall h\in H\setminus\{0\}\}$. Every element of $H\setminus\{0\}$ has the form $(m+r_i)+h'$ with $h'\in H$. So $x\in\operatorname{PF}(H_\lambda)$ if and only if $x\notin H_\lambda$ and $x+m+r_i\in H_\lambda$ for all $i$. (Such an $x$ is automatically positive when $H\ne\mathbb N$. Otherwise $h=F(H)-x>F(H)$ would give $x+h=F(H)\notin H$. So it makes no difference whether non-elements are taken in $\mathbb Z$ or in $\mathbb N$.)
* $\operatorname{tr}(H)$ and $\operatorname{res}(H)$ are as in CLAIM.md.

## 2. The lattice model

**Lemma 1 (lattice model).** Let $\lambda\ge0$.
(a) $\pi_\lambda:\Lambda\to\mathbb Z$ is a surjective group homomorphism with kernel $\mathbb Z v_\lambda$.
(b) $H_\lambda=\pi_\lambda(T)$ and $\pi_\lambda(g_i)=m+r_i$. Also, $H_\lambda$ is a numerical semigroup.
(c) For $y\in\Lambda$: $\chi(y)=1\iff y\in T+\mathbb Z v$. In particular $\chi(y+jv)=\chi(y)$ for all $j\in\mathbb Z$, and $\chi(y)=1$ for $y\in T$.
(d) Every coset $y+\mathbb Zv$ meets $\Sigma_\lambda$ in exactly one point, called the *canonical lift*. Hence $\pi_\lambda|_{\Sigma_\lambda}:\Sigma_\lambda\to\mathbb Z$ is a bijection.

*Proof.*
(a) $\pi_\lambda$ is additive. Also $(0,w),(d,w-d)\in\Lambda$ with $\pi_\lambda(0,w)=m$ and $\pi_\lambda(d,w-d)=m+d$, so the image contains $\gcd(m,d)=1$.
For the kernel, let $(a,b)\in\Lambda$ with $a+b=sw$ and $\pi_\lambda(a,b)=a+sm=0$. Then $a=-sm$. Since $d\mid a$ and $\gcd(m,d)=1$, $d\mid s$; write $s=dj$. Then $a=-djm$ and $b=sw-a=dj(w+m)=djM$, so $(a,b)=jv$. Conversely, $v\in\Lambda$ (because $-dm+dM=dw$) and $\pi_\lambda(v)=(-dmM+dMm)/w=0$.
(b) An element $\sum_i c_i(m+r_i)$ of $H_\lambda$ equals $sm+a$ with $s=\sum c_i$ and $a=\sum c_ir_i\in sR$. This is $\pi_\lambda(a,sw-a)$. Conversely, every $(a,sw-a)\in T$ maps to $sm+a\in H_\lambda$. Moreover $\gcd(m+r_0,\dots,m+r_k)=\gcd(m,r_1,\dots,r_k)=\gcd(m,d)=1$.
(c) follows from (a) and (b).
(d) The first coordinates of $y+jv$ are $y_1-jdm$, with $y_1\in d\mathbb Z$. Exactly one $j$ puts this coordinate in $[0,dm)$. $\square$

**Lemma 2 (structure of $T$).** Hypotheses: notation of §1.
(a) $T$ is a submonoid of $\Lambda\cap\mathbb N^2$ containing every $g_i$, and $T\subseteq T^*$.
(b) Put $s_0=\lceil 2(c+w)/d\rceil$. If $(a,b)\in T^*$ and $a+b\ge s_0w$, then $(a,b)\in T$.

*Proof.*
(a) $sR+s'R=(s+s')R$, so $T$ is a monoid. For $s=1$ and $a=r_i$ we get $g_i\in T$. If $a=r_{i_1}+\dots+r_{i_s}$, then $a\in S\cap d\mathbb Z$ and $sw-a=\sum_j(w-r_{i_j})\in S'$. Both coordinates are $\ge0$ and the coordinate sum is $sw$.

(b) For $x\in S$, let $\ell(x)$ be the least number of nonzero elements of $R$ with sum $x$, so $\ell(0)=0$. Padding with $r_0=0$ shows that $x\in jR$ for every $j\ge\ell(x)$.

*Claim:* $\ell(x)\le x/w+(c+w)/d$.
* If $x<c+w$: each nonzero element of $R$ is $\ge d$, so $\ell(x)\le x/d<(c+w)/d$.
* If $x\ge c+w$: let $q=\lfloor (x-c)/w\rfloor\ge1$ and $y=x-qw$. Then $y\in[c,c+w)\cap d\mathbb Z$, so $y\in S$, and the first case gives $\ell(y)<(c+w)/d$. Since $w=r_k$ is a nonzero element of $R$, $\ell(x)\le q+\ell(y)\le x/w+(c+w)/d$.

The same argument applies to $R'$ (whose maximum is also $w$) and to $\ell'$, defined for $S'$ in the same way. So $\ell'(x)\le x/w+(c+w)/d$.

Now let $(a,b)\in T^*$. Then $a,b\ge0$ and $a+b\in w\mathbb Z$, so $a+b=sw$ with $s\ge s_0\ge 2(c+w)/d$.
* If $a\le b$: $a\le sw/2$, so $\ell(a)\le s/2+s/2=s$. Hence $a\in sR$ and $(a,b)=(a,sw-a)\in T$.
* If $b<a$: in the same way $\ell'(b)\le s$, so $b\in sR'$. That is, $b=\sum_{j=1}^s(w-r_{i_j})$, so $a=sw-b=\sum_j r_{i_j}\in sR$, and $(a,b)\in T$. $\square$

**Lemma 3 (membership criterion on the canonical strip).** Hypotheses: $dm\ge\max(c,s_0w)$ and $(a,b)\in\Sigma_\lambda$. Then
$$\chi(a,b)=1\iff (a,b)\in T\ \text{ or }\ b-dM\in S'.$$

*Proof.* By Lemma 1(c), $\chi(a,b)=1$ if and only if $(a,b)+jv=(a-jdm,\ b+jdM)$ lies in $T$ for some $j$.
* For $j\ge1$, the first coordinate is negative, so the point is not in $T\subseteq\mathbb N^2$.
* For $j=0$, the condition is $(a,b)\in T$.
* For $j=-i$ with $i\ge1$: if $(a+idm,\ b-idM)\in T\subseteq T^*$, then $b-idM\in S'$. Since $dM\ge c$ is a multiple of $d$, we have $dM\in S'$, and so $b-dM=(b-idM)+(i-1)dM\in S'$.

Conversely, suppose $b-dM\in S'$. Then $(a+dm,\ b-dM)=(a,b)-v\in\Lambda$, and $a+dm\ge c$ is a multiple of $d$, so it lies in $S$. Hence $(a,b)-v\in T^*$. Its coordinate sum is $\ge dm\ge s_0w$, so $(a,b)-v\in T$ by Lemma 2(b). $\square$

## 3. Constants and local rules

Fix the following constants, none of which depend on $\lambda$:
$$c'=c+s_0w,\qquad D=c'+w,\qquad K=c'+D=2c'+w .$$
Let $L$ be the least integer $\lambda\ge0$ with $d(n+\lambda w)\ge 6K$.

Since $s_0\ge 2w/d\ge2$, we have $0<w\le c'$. Also $c\le c'$, $s_0w\le c'$, $D\le K$, and for $\lambda\ge L$ we have $dM>dm\ge6K$.

**(F)** Let $(a,b)\in\Lambda$. If $a\ge c'$ then $a\in S$; if $b\ge c'$ then $b\in S'$. If ($a\ge c'$ and $b\in S'$), or ($a\in S$ and $b\ge c'$), then $(a,b)\in T$. This holds because the coordinates lie in $d\mathbb Z$, and the coordinate sum is then $\ge c'\ge s_0w$, so Lemma 2(b) applies.

**Lemma 4 (local rules).** Hypotheses: $\lambda\ge L$ and $(a,b)\in\Lambda$.
* (D) If $a\ge c'$ and $b\ge c'$, then $\chi(a,b)=1$. If $a\ge c'-dm$ and $b\ge dM+c'$, then $\chi(a,b)=1$.
* (N) If $-dm\le a<dm$ and $b<0$, then $\chi(a,b)=0$.
* (O) If $|a|,|b|\le 2K$, then $\chi(a,b)=[(a,b)\in T]$.
* (P) If $z=(z_1,z_2)\in\Lambda'$ with $|z_1|,|z_2|\le 2K$, then $\chi(P+z)=[\,z_1\in S\ \text{or}\ z_2\in S'\,]$.
* (Bot) If $c'\le a<dm$ and $|b|\le 2K$, then $\chi(a,b)=[b\in S']$.
* (Left) If $|a|\le2K$ and $c'\le b<dM$, then $\chi(a,b)=[a\in S]$.

*Proof.* Lemma 3 applies, since $dm\ge 6K\ge\max(c,s_0w)$.
* (D) In the first case $(a,b)\in T$ by (F). In the second case, $(a,b)-v=(a+dm,\,b-dM)$ has both coordinates $\ge c'$, so it lies in $T$, and then $\chi(a,b)=1$ by Lemma 1(c).
* (N) If $a\ge0$, the point is canonical. It is not in $T$ (since $b<0$) and $b-dM<0$, so $b-dM\notin S'$; Lemma 3 gives $0$. If $a<0$, the canonical lift is $(a+dm,\,b-dM)$, whose second coordinate is negative, and the same argument gives $0$.
* (O) If $b<0$, the point is not in $T$ and (N) gives $\chi=0$, since $-dm<-2K\le a\le 2K<dm$. If $b\ge0>a$, the point is not in $T$; its canonical lift $(a+dm,b-dM)$ has negative second coordinate, so $\chi=0$ by (N). If $a,b\ge0$, the point is canonical and $b-dM\le 2K-dM<0$, so Lemma 3 gives $\chi=[(a,b)\in T]$.
* (P) If $z_1\ge0$: $P+z=(z_1,\,dM+z_2)$ is canonical. Its second coordinate is $\ge dM-2K\ge c'$, so by (F) and $T\subseteq T^*$, $P+z\in T\iff z_1\in S$. Moreover $(dM+z_2)-dM=z_2$. Lemma 3 gives $\chi=[z_1\in S\text{ or }z_2\in S']$.
  If $z_1<0$: the canonical lift is $P+z-v=(z_1+dm,\ z_2)$, with $z_1+dm\ge dm-2K\ge c'$. By (F) and $T\subseteq T^*$ it lies in $T$ if and only if $z_2\in S'$. Also $z_2-dM<0$. So $\chi=[z_2\in S']=[z_1\in S\text{ or }z_2\in S']$, because $z_1<0$ implies $z_1\notin S$.
* (Bot) The point is canonical and $b-dM<0$. By (F) and $T\subseteq T^*$, $(a,b)\in T\iff b\in S'$.
* (Left) If $a\ge0$: the point is canonical, $b-dM<0$, and $(a,b)\in T\iff a\in S$ by (F). If $a<0$: the canonical lift $(a+dm,b-dM)$ has negative second coordinate, so $\chi=0=[a\in S]$ by (N). $\square$

## 4. Pseudo-Frobenius numbers

Define two finite sets, neither of which depends on $\lambda$:
$$\Phi_O=\{e\in\Lambda:\ 0\le e_1,e_2<c',\ e\notin T,\ e+g_i\in T\ (0\le i\le k)\},$$
$$\Phi_P=\{z\in\Lambda':\ -w\le z_1,z_2<c,\ z_1\notin S,\ z_2\notin S',\ \forall i:\ z_1+r_i\in S\ \text{or}\ z_2+w-r_i\in S'\}.$$

**Lemma 5 (PF set).** Hypothesis: $\lambda\ge L$. Then
$$\operatorname{PF}(H_\lambda)=\pi_\lambda(\Phi_O)\cup\pi_\lambda(P+\Phi_P),$$
and $\pi_\lambda$ is injective on $\Phi_O\cup(P+\Phi_P)$.

*Proof.* We first show that each candidate is a pseudo-Frobenius number.
* For $e\in\Phi_O$, the points $e$ and $e+g_i$ have coordinates in $[0,c'+w]\subseteq[-2K,2K]$. By rule (O), $\chi(e)=0$ and $\chi(e+g_i)=1$. So $\pi(e)\notin H_\lambda$ and $\pi(e)+m+r_i\in H_\lambda$ for every $i$, which means $\pi(e)\in\operatorname{PF}$.
* For $z\in\Phi_P$, the points $z$ and $z+g_i$ lie in $\Lambda'$ with coordinates in $[-w,c+w]$. Rule (P) gives $\chi(P+z)=0$ and $\chi(P+z+g_i)=1$.

Conversely, let $x\in\operatorname{PF}(H_\lambda)$ with canonical lift $y=(a,b)$, so $0\le a<dm$. By Lemma 3, $x\notin H$ means $y\notin T$ and $b-dM\notin S'$.

*Case I: $a+w<dm$.* Then $y+g_k=(a+w,b)$ is canonical and $\chi=1$ there. Since $b-dM\notin S'$, Lemma 3 gives $(a+w,b)\in T\subseteq T^*$, so $b\in S'$.
* (I.1) If $a\in S$, then $y\in T^*\setminus T$. Lemma 2(b) gives $a+b<s_0w\le c'$, so $y\in[0,c')^2$.
* (I.2) If $a\notin S$, then $a<c$. The point $y+g_0=(a,b+w)$ is canonical, has $\chi=1$, and is not in $T^*\supseteq T$. So Lemma 3 gives $b+w-dM\in S'$, hence $b-dM\ge -w$. Also $b-dM\notin S'$ and $b-dM\in d\mathbb Z$, so $b-dM<c$. Then $y=P+z$ with $z=(a,b-dM)\in[0,c)\times[-w,c)$.

*Case II: $a+w\ge dm$.* Then $a\ge dm-w\ge c'$, so $a\in S$.
* If $b\in S'$, then $y\in T^*$ with coordinate sum $\ge c'$, so $y\in T$ by Lemma 2(b), a contradiction. Hence $b\notin S'$.
* The point $y+g_0=(a,b+w)$ is canonical with $\chi=1$. If $b+w-dM\in S'$, then $b\ge dM-w\ge c$ and so $b\in S'$, a contradiction. So by Lemma 3, $(a,b+w)\in T$, which gives $b+w\in S'$ and therefore $b\ge-w$.
* Since $b\notin S'$, $b<c$.

Hence $y+v=P+z$ with $z=(a-dm,\,b)\in[-w,0)\times[-w,c)$.

In every case the lift is either some $e\in\Lambda\cap[0,c')^2$, or $P+z$ with $z\in\Lambda'\cap[-w,c)^2$. The same rules (O) and (P) used above show that being in $\operatorname{PF}$ is then exactly the condition $e\in\Phi_O$, respectively $z\in\Phi_P$.

*Injectivity.* The canonical lifts are as follows:
* for $e\in\Phi_O$, the lift is $e$, which lies in $[0,c')^2$;
* for $z\in\Phi_P$ with $z_1\ge0$, the lift is $(z_1,dM+z_2)$, whose second coordinate is $\ge dM-w>c'$;
* for $z\in\Phi_P$ with $z_1<0$, the lift is $(z_1+dm,z_2)$, whose first coordinate is $\ge dm-w>c'$.

These lifts are pairwise distinct, and Lemma 1(d) then gives injectivity. $\square$

## 5. The trace through lifts

Put $\widehat\Phi=\Phi_O\cup(P+\Phi_P)\subseteq\Lambda$. This set is nonempty: $m\ge 6K/d\ge 2$ implies $1\notin H_\lambda$, so $F(H_\lambda)\in\operatorname{PF}$. Let
$$\Delta_0=(\Phi_O-\Phi_O)\cup(\Phi_P-\Phi_P)\subseteq\Lambda,\qquad \Delta_+=\Phi_P-\Phi_O\subseteq\Lambda',\qquad \Delta_-=\Phi_O-\Phi_P .$$
These are finite sets that do not depend on $\lambda$. Every coordinate of every element of them has absolute value $<D$, because $\Phi_O\subseteq[0,c')^2$, $\Phi_P\subseteq[-w,c)^2$ and $c\le c'$.

**Lemma 6 (trace criterion).** Hypotheses: $\lambda\ge L$, $h\in H_\lambda$, and $y\in\Lambda$ any lift of $h$. Then $h\in\operatorname{tr}(H_\lambda)$ if and only if $\tau(y)$ holds, where
$$\tau(y):\quad \bigvee_{p\in\Phi_P}\Big[\bigwedge_{f\in\Phi_P}\chi(y+p-f)\wedge\bigwedge_{e\in\Phi_O}\chi(y+P+(p-e))\Big]\ \vee\ \bigvee_{e\in\Phi_O}\Big[\bigwedge_{e'\in\Phi_O}\chi(y+e-e')\wedge\bigwedge_{f\in\Phi_P}\chi(y-P+(e-f))\Big].$$
In particular, $\tau(y)$ is a fixed Boolean function, independent of $\lambda$, of the **profile** of $y$:
$$\big(\chi(y+\delta)\big)_{\delta\in\Delta_0},\quad \big(\chi(y+P+\delta)\big)_{\delta\in\Delta_+},\quad \big(\chi(y-P+\delta)\big)_{\delta\in\Delta_-}.$$
Also $\tau(y+v)=\tau(y)$.

*Proof.* By Lemma 5, $\pi_\lambda$ maps $\widehat\Phi$ onto $\operatorname{PF}(H_\lambda)$. For $u,u'\in\widehat\Phi$, linearity gives $h+\pi(u)-\pi(u')=\pi(y+u-u')$. The condition defining $\operatorname{tr}$ is therefore $\exists u\,\forall u':\chi(y+u-u')=1$.

The four possible types of $(u,u')$ produce the four kinds of terms:
* $(P+p,\ P+f)$ gives $p-f$;
* $(P+p,\ e)$ gives $P+(p-e)$;
* $(e,\ e')$ gives $e-e'$;
* $(e,\ P+f)$ gives $-P+(e-f)$.

Invariance under $v$ follows from Lemma 1(c). $\square$

## 6. Regions of the strip

For $\lambda\ge L$, split $\Sigma_\lambda^{+}=\{(a,b)\in\Sigma_\lambda: b\ge0\}$ into five disjoint regions. Disjointness and covering use $dm,dM\ge 6K>2K$.

* $\mathcal R_O$: $a<K,\ b<K$.
* $\mathcal R_{bot}$: $K\le a<dm-K,\ b<K$.
* $\mathcal R_{left}$: $a<K,\ K\le b<dM-K$.
* $\mathcal R_P$: ($a\ge dm-K,\ b<K$) or ($a<K,\ dM-K\le b\le dM+K$).
* $\mathcal R_{deep}$: ($a\ge K,\ b\ge K$) or ($a<K,\ b>dM+K$).

By rule (N), every canonical lift $y$ with $\chi(y)=1$ lies in $\Sigma_\lambda^+$. By Lemmas 1(d) and 6,
$$\operatorname{res}(H_\lambda)=\#\{y\in\Sigma^+_\lambda:\ \chi(y)=1,\ \neg\tau(y)\}. \tag{$\ast$}$$

**Lemma 7 (deep region).** Hypotheses: $\lambda\ge L$ and $y\in\mathcal R_{deep}$. Then $\chi(y)=1$ and $\tau(y)$ holds.

*Proof.* It is enough to show $\chi(y+\delta)=1$ for every $\delta$ with $|\delta_i|<D$, and $\chi(y+P+\delta)=1$ for every $\delta\in\Delta_+$. This suffices for $\tau$ for the following reason:
* If $\Phi_P\ne\emptyset$, take any $p\in\Phi_P$ in the first disjunct of $\tau$. It only involves shifts $y+\delta$ with $\delta\in\Delta_0$ and $y+P+\delta$ with $\delta\in\Delta_+$.
* If $\Phi_P=\emptyset$, then $\Phi_O\neq\emptyset$ because $\widehat\Phi\neq\emptyset$. Take any $e\in\Phi_O$ in the second disjunct; it only involves $\Delta_0$-shifts.

Now the two cases of $\mathcal R_{deep}$:
* If $a,b\ge K$: the coordinates of $y+\delta$ and of $y+P+\delta$ are all $\ge K-D=c'$, so (D) applies.
* If $a<K$ and $b>dM+K$: the first coordinates are $\ge -D\ge c'-dm$, and the second coordinates are $\ge dM+K-D=dM+c'$, so the second form of (D) applies.

Taking $\delta=0$ gives $\chi(y)=1$. $\square$

**Lemma 8 (bottom strip).** Hypotheses: $\lambda\ge L$ and $y=(a,b)\in\mathcal R_{bot}$. Then $\chi(y)=[b\in S']$, and $\tau(y)=\beta(b)$ for a predicate $\beta$ on $d\mathbb Z\cap[0,K)$ that does not depend on $\lambda$.

*Proof.* We compute the profile.
* For $\delta\in\Delta_0$ (or $\delta=0$): $c'=K-D\le a+\delta_1<dm-K+D<dm$ and $|b+\delta_2|<K+D\le2K$. So (Bot) gives $\chi(y+\delta)=[b+\delta_2\in S']$.
* For $\delta\in\Delta_+$: $y+P+\delta=(a+\delta_1,\ b+dM+\delta_2)$ has both coordinates $\ge c'$, so its value is $1$ by (D).
* For $\delta\in\Delta_-$: $y-P+\delta$ has first coordinate in $[0,dm)$ and second coordinate $<K+D-dM<0$, so its value is $0$ by (N).

So the profile depends only on $b$, and Lemma 6 applies. $\square$

**Lemma 9 (left strip).** Hypotheses: $\lambda\ge L$ and $y=(a,b)\in\mathcal R_{left}$. Then $\chi(y)=[a\in S]$, and $\tau(y)=\alpha(a)$ for a predicate $\alpha$ on $d\mathbb Z\cap[0,K)$ that does not depend on $\lambda$.

*Proof.* We compute the profile.
* For $\delta\in\Delta_0\cup\{0\}$: $|a+\delta_1|\le K+D\le2K$ and $c'=K-D\le b+\delta_2<dM-K+D<dM$. So (Left) gives $\chi(y+\delta)=[a+\delta_1\in S]$.
* For $\delta\in\Delta_+$: $y+P+\delta$ has first coordinate $\ge -D\ge c'-dm$ and second coordinate $\ge dM+K-D=dM+c'$, so its value is $1$ by (D).
* For $\delta\in\Delta_-$: $y-P+\delta$ has first coordinate in $[-2K,2K]\subseteq[-dm,dm)$ and second coordinate $<dM-K+D-dM=-c'<0$, so its value is $0$ by (N). $\square$

**Lemma 10 (corners).** Hypothesis: $\lambda\ge L$.
(a) $\mathcal R_O=\Lambda\cap[0,K)^2$, which does not depend on $\lambda$. For $y\in\mathcal R_O$, $\chi(y)=[y\in T]$, and $\tau(y)=\theta_O(y)$ for a predicate $\theta_O$ that does not depend on $\lambda$.
(b) Put $Z_P=\Lambda'\cap\big([-K,0)\times[0,K)\ \cup\ [0,K)\times[-K,K]\big)$, which does not depend on $\lambda$. The map
$$z\mapsto y(z)=\begin{cases}(z_1+dm,\ z_2)=P+z-v,& z_1<0,\\ (z_1,\ dM+z_2)=P+z,& z_1\ge0\end{cases}$$
is a bijection $Z_P\to\mathcal R_P$. Moreover $\chi(y(z))=[z_1\in S\text{ or }z_2\in S']$, and $\tau(y(z))=\theta_P(z)$ for a predicate $\theta_P$ that does not depend on $\lambda$.

*Proof.*
(a) Membership follows from (O). For the profile:
* For $\delta\in\Delta_0$: $y+\delta$ has coordinates in $(-D,K+D)\subseteq[-2K,2K]$, so rule (O) gives $[y+\delta\in T]$.
* For $\delta\in\Delta_+$: $y+P+\delta=P+(y+\delta)$ with $y+\delta\in\Lambda'$ and coordinates bounded by $2K$, so rule (P) gives $[(y+\delta)_1\in S\text{ or }(y+\delta)_2\in S']$.
* For $\delta\in\Delta_-$: $y-P+\delta$ has first coordinate in $[-2K,2K]$ and second coordinate $<K+D-dM<0$, so rule (N) gives $0$.

All three are independent of $\lambda$.

(b) The two pieces of $\mathcal R_P$ are $a\ge dm-K$ and $a<K$. They are disjoint because $dm>2K$. The displayed map and its inverse $y\mapsto (a-dm,b)$, resp. $y\mapsto(a,b-dM)$, are mutually inverse between these sets. They respect the lattices because $\Lambda'=\Lambda-P$ and $v\in\Lambda$.

Since $y(z)\equiv P+z\pmod v$, Lemmas 1(c) and 6 let us use the lift $P+z$, with $|z_i|\le K$. Rule (P) gives $\chi$. For the profile:
* For $\delta\in\Delta_0$: $P+(z+\delta)$ with $|z_i+\delta_i|\le2K$, so rule (P) applies.
* For $\delta\in\Delta_+$: $2P+z+\delta-v=(z_1+\delta_1+dm,\ dM+z_2+\delta_2)$ has both coordinates $\ge 6K-2K\ge c'$, so its value is $1$ by (D).
* For $\delta\in\Delta_-$: $P+z-P+\delta=z+\delta\in\Lambda$ has coordinates bounded by $2K$, so rule (O) gives $[z+\delta\in T]$.

All of these are independent of $\lambda$. $\square$

## 7. Counting and the main theorem

**Lemma 11 (counting in a growing interval).** Hypotheses: $X,\rho,Y_0\in\mathbb Z$, $Y_\lambda=Y_0+\lambda dw$, and $N(\lambda)=\#\{x\in\mathbb Z:\ X\le x<Y_\lambda,\ x\equiv\rho\pmod w\}$. Then $N(\lambda+1)=N(\lambda)+d$ whenever $Y_\lambda\ge X$.

*Proof.* The new integers form the block $[Y_\lambda,Y_\lambda+dw)$ of $dw$ consecutive integers, which contains exactly $d$ integers from each residue class mod $w$. $\square$

**Theorem.** Hypotheses: integers $k\ge1$ (in particular $k\ge2$), $0=r_0<\dots<r_k=w$, $d=\gcd(r_1,\dots,r_k)$, $n>0$ with $\gcd(n,d)=1$, and $H_\lambda=\langle n+\lambda w+r_i:0\le i\le k\rangle$. Let $L$, $K$, $\beta$, $\alpha$, $\theta_O$, $\theta_P$ be as above, and set
$$\mathfrak B=\{b\in d\mathbb Z\cap[0,K):\ b\in S',\ \neg\beta(b)\},\qquad \mathfrak A=\{a\in d\mathbb Z\cap[0,K):\ a\in S,\ \neg\alpha(a)\}.$$
Then there is an integer $B$ such that
$$\operatorname{res}(H_\lambda)=A\lambda+B\quad\text{for every integer }\lambda\ge L,\qquad A=d\,(|\mathfrak A|+|\mathfrak B|)\ \ge 0.$$

*Proof.* Let $\lambda\ge L$. Split the count $(\ast)$ over the five regions.

* **Deep region.** By Lemma 7, $\mathcal R_{deep}$ contributes $0$.
* **Corner $O$.** By Lemma 10(a), $\mathcal R_O$ contributes $N_O=\#\{y\in\Lambda\cap[0,K)^2:\ y\in T,\ \neg\theta_O(y)\}$.
* **Corner $P$.** By Lemma 10(b), $\mathcal R_P$ contributes $N_P=\#\{z\in Z_P:\ (z_1\in S\text{ or }z_2\in S'),\ \neg\theta_P(z)\}$.

  Neither $N_O$ nor $N_P$ depends on $\lambda$.
* **Bottom strip.** For $b\in d\mathbb Z$, the points $(a,b)\in\Lambda$ are exactly those with $a\equiv -b\pmod w$; this already forces $a\in d\mathbb Z$, since $d\mid w$. So by Lemma 8, $\mathcal R_{bot}$ contributes
$$\sum_{b\in\mathfrak B}\#\{a:\ K\le a<dm_\lambda-K,\ a\equiv -b\ (\mathrm{mod}\ w)\}.$$
* **Left strip.** By Lemma 9, $\mathcal R_{left}$ contributes
$$\sum_{a\in\mathfrak A}\#\{b:\ K\le b<dM_\lambda-K,\ b\equiv -a\ (\mathrm{mod}\ w)\}.$$

The upper limits are $dm_\lambda-K=(dn-K)+\lambda dw$ and $dM_\lambda-K=(dn+dw-K)+\lambda dw$. Both are $\ge K$ for $\lambda\ge L$. By Lemma 11, each summand equals its value at $\lambda=L$ plus $d(\lambda-L)$. Therefore
$$\operatorname{res}(H_\lambda)=N_O+N_P+\sum_{b\in\mathfrak B}\big(C_b+d(\lambda-L)\big)+\sum_{a\in\mathfrak A}\big(C'_a+d(\lambda-L)\big),$$
where the constants $C_b,C'_a$ are the counts at $\lambda=L$. This is $A\lambda+B$ with $A=d(|\mathfrak A|+|\mathfrak B|)\ge0$ and
$$B=N_O+N_P+\sum_{\mathfrak B}(C_b-dL)+\sum_{\mathfrak A}(C'_a-dL)\in\mathbb Z. \qquad\square$$

This answers the question in CLAIM.md affirmatively.

## 8. Remarks: stronger statements that the proof also gives

All of the following are proved above, or follow directly from the lemmas as indicated.

1. **$k\ge1$ suffices.** The hypothesis $k\ge2$ is never used.
2. **The whole shifted family, with period $w/d$.** Put $W=w/d$, call an integer $m$ *admissible* if $m>0$ and $\gcd(m,d)=1$, and write $\operatorname{res}(m)=\operatorname{res}\langle m+r_0,\dots,m+r_k\rangle$.
   The constants $c,s_0,c',D,K$ depend only on $R$. The arguments of §§1–7 use $n$ only through $m$ and through the coset $\Lambda'$, which is determined by $dm\bmod w$. Since $d(m+W)=dm+w$, this is in turn determined by $m\bmod W$. Hence the finite sets $\Phi_O,\Phi_P,Z_P$, the predicates $\beta,\alpha,\theta_O,\theta_P$, the sets $\mathfrak A,\mathfrak B$ and the corner counts $N_O,N_P$ depend only on $\rho=m\bmod W$; write $\mathfrak A_\rho,\mathfrak B_\rho,N_{O,\rho},N_{P,\rho}$.
   Let $m$ be admissible with $dm\ge 6K$. Apply the Theorem with $n=m$ and $\lambda=0$; then $L=0$. Its proof gives
   $$\operatorname{res}(m)=N_{O,\rho}+N_{P,\rho}+\sum_{b\in\mathfrak B_\rho}N_b(m)+\sum_{a\in\mathfrak A_\rho}N'_a(m),$$
   where $N_b(m)=\#\{x:K\le x<dm-K,\ x\equiv-b\ (\mathrm{mod}\ w)\}$ and $N'_a(m)=\#\{x:K\le x<dm+dw-K,\ x\equiv -a\ (\mathrm{mod}\ w)\}$.
   Now let $m'=m+tW$ with $t\ge0$, and suppose $m'$ is also admissible. Then $dm'=dm+tw$. Each interval gains the block $[dm-K,\,dm-K+tw)$ (respectively the analogous block for $N'$), and this block has $tw$ consecutive integers, so it contains exactly $t$ integers from each residue class mod $w$. Therefore
   $$\operatorname{res}(m+tW)-\operatorname{res}(m)=t\,\big(|\mathfrak A_\rho|+|\mathfrak B_\rho|\big).$$
   Consequently, for each $\rho\in\mathbb Z/W$ there is an affine function $Q_\rho(m)=\frac{|\mathfrak A_\rho|+|\mathfrak B_\rho|}{W}\,m+\gamma_\rho$ with $\gamma_\rho\in\mathbb Q$ such that $\operatorname{res}(m)=Q_\rho(m)$ for every admissible $m\equiv\rho\pmod W$ with $dm\ge 6K$. So on the admissible domain, $\operatorname{res}$ is eventually a quasi-polynomial of degree $\le1$ with period dividing $W=w/d$. This improves the period $w$ given by applying the Theorem to each $n\in\{1,\dots,w\}$ separately. The statement is about admissible $m$ only; some integers in the class $\rho$ may be inadmissible, for example when $d>1$ and $W=1$. The slope in $m$ is $d(|\mathfrak A|+|\mathfrak B|)/w$, as before. The slope in $\lambda$ along $m=n+\lambda w$ (step $w=dW$) is $A=d(|\mathfrak A|+|\mathfrak B|)$, which is always a multiple of $d$.
3. **Pseudo-Frobenius set and type.** By Lemma 5, for $\lambda\ge L$ the pseudo-Frobenius numbers are given by the local data $\Phi_O,\Phi_P$, which do not depend on $\lambda$. The type is eventually constant: $t(H_\lambda)=|\Phi_O|+|\Phi_P|$.
4. **Nearly Gorenstein is eventually constant.** $\operatorname{tr}(H)$ is closed under adding elements of $H$: if $h+p-f\in H$ for all $f$, then the same holds for $h+h'$. So $H_\lambda\setminus\{0\}\subseteq\operatorname{tr}(H_\lambda)$ if and only if every $m+r_i=\pi(g_i)$ lies in the trace. Each $g_i$ is canonical and lies in $\mathcal R_O$, since its coordinates are at most $w<K$. So by Lemma 10(a) this condition reads $\theta_O(g_0)\wedge\dots\wedge\theta_O(g_k)$, which does not depend on $\lambda\ge L$.
5. **Bounded versus linear growth.** $\operatorname{res}(H_\lambda)$ is eventually constant if and only if $\mathfrak A=\mathfrak B=\emptyset$. Otherwise it grows linearly, with slope at least $d$.
6. **Illustration (by hand; the proof does not use it).** Take $R=\{0,1,\dots,w\}$. Then $S=S'=\mathbb N$, $c=0$, $T=T^*$ and $\Phi_O=\emptyset$. Here $\Phi_P$ consists of the pairs $(-\alpha,-\beta')$ with $\alpha,\beta'\ge1$, $\alpha+\beta'=\nu$, where $\nu\in[2,w+1]$ and $\nu\equiv n\pmod w$. So $|\Phi_P|=\nu-1$, which is the known type of interval semigroups. Choosing $p$ with $p_2=-1$ (respectively $p_1=-1$) shows that $\beta$ and $\alpha$ hold everywhere. So $A=0$, and $\operatorname{res}$ is eventually constant for interval generators.
7. **Other profile counts: what extends, and what does not.** An earlier draft suggested an unrestricted extension: any count of $h$ by a condition on finitely many bounded shifts of its lift, together with shifts by $\pm P$. That extension is **false**. Take $R=\{0,1,2\}$ (so $w=2$, $d=1$), $n=2$, $m=2+2\lambda$, $M=m+2$. Then $q_\lambda=\pi_\lambda(P)=mM/2=(\lambda+2)m\in H_\lambda$. The count $I_\lambda=\#\{h\in H_\lambda: h-q_\lambda\notin H_\lambda\}$ is defined by the profile condition $\chi(y)=1\wedge\chi(y-P)=0$. Each residue class mod $q_\lambda$ has exactly one least element of $H_\lambda$, and since $q_\lambda\in H_\lambda$ these least elements are exactly the $h$ counted. So $I_\lambda=q_\lambda=2\lambda^2+6\lambda+4$, which is quadratic. The failure is in the deep region: there the shifts $y-P+\delta$ are not controlled by any local rule.
   What the argument does prove is the following. Let $\Delta\subseteq\Lambda$, $\Delta^+\subseteq\Lambda'$ and $\Delta^-\subseteq-\Lambda'$ be finite sets with $0\in\Delta$. Let $\Psi$ be a Boolean function of the profile $\big(\chi(y+\delta)\big)_{\Delta},\big(\chi(y+P+\delta)\big)_{\Delta^+},\big(\chi(y-P+\delta)\big)_{\Delta^-}$. Suppose that $\Psi$ is false whenever all the entries indexed by $\Delta$ and $\Delta^+$ equal $1$, whatever the $\Delta^-$ entries are. Then $I_\lambda=\#\{h\in H_\lambda:\Psi(\text{profile of a lift of }h)\}$ is eventually affine in $\lambda$, with slope a nonnegative multiple of $d$.
   *Proof.* By Lemma 1(c), the profile does not depend on the choice of lift. Replace $D$ by $D^*=\max\big(c'+w,\ 1+\max\{|\delta_i|:\delta\in\Delta\cup\Delta^+\cup\Delta^-\}\big)$. Replace $K$ by $K^*=c'+D^*$, and $L$ by the least $L^*$ with $d(n+L^*w)\ge6K^*$.
   Rules (D), (N), (O), (P), (Bot), (Left) and Lemma 5 hold unchanged, because their proofs use only $K\ge c'+w$ and $dm\ge 6K$. Since only $h\in H_\lambda$ are counted, rule (N) again confines the canonical lifts to $\Sigma^+_\lambda$.
   The proof of Lemma 7 shows that every $\Delta$-entry and every $\Delta^+$-entry equals $1$ on $\mathcal R_{deep}$. So by the hypothesis on $\Psi$, the deep region contributes $0$.
   The proofs of Lemmas 8–10 show that on the other regions the whole profile is a $\lambda$-independent function: of $b$ on $\mathcal R_{bot}$, of $a$ on $\mathcal R_{left}$, and of $y$ (respectively $z$) on the corners. There the $\Delta^-$-entries are given by (N) or (O). The counting in the proof of the Theorem then goes through word for word.
   The trace residue is the case $\Delta=\Delta_0\cup\{0\}$, $\Delta^\pm=\Delta_\pm$ and $\Psi=\chi(y)\wedge\neg\tau(y)$. For this $\Psi$, the hypothesis is exactly what the proof of Lemma 7 verifies. The counterexample above shows that the hypothesis cannot be dropped: its condition $\chi(y)\wedge\neg\chi(y-P)$ uses a $-P$ shift whose value varies across the deep region.
8. **$\Phi_P$ is never empty.** Let $C=\{z\in\Lambda': z_1\notin S,\ z_2\notin S'\}$. It is nonempty, because it contains points with both coordinates negative. Every multiple of $d$ that is $\ge c$ lies in $S\cap S'$, so on $C$ we have $z_1,z_2<c$. Hence $z_1+z_2$ is bounded above on $C$; choose $z\in C$ with $z_1+z_2$ maximal.
   For each $i$, the point $z+g_i\in\Lambda'$ has a larger coordinate sum, so $z+g_i\notin C$. That is, $z_1+r_i\in S$ or $z_2+w-r_i\in S'$. For $i=k$ this gives $z_1+w\in S$ (since $z_2\notin S'$), so $z_1\ge-w$. For $i=0$ it gives $z_2+w\in S'$ (since $z_1\notin S$), so $z_2\ge -w$. Therefore $z\in\Phi_P$.
   Consequently the branch "$\Phi_P=\emptyset$" in the proof of Lemma 7 never occurs; it is harmless but vacuous. By Remark 3, $t(H_\lambda)\ge 1+|\Phi_O|$ for $\lambda\ge L$.
