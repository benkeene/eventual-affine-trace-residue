## 3. Definition audit

`Challenge.lean` has four definitions, all in namespace `EventualAffineTraceResidue`; `EventualAffineTraceResidue/Basic.lean` restates them with the same bodies and docstrings, and the development and `Solution.lean` use those copies.

- `shiftedSemigroup (k : ℕ) (r : Fin (k + 1) → ℤ) (n w l : ℤ) : AddSubmonoid ℤ := AddSubmonoid.closure (Set.range fun i : Fin (k + 1) => n + l * w + r i)`. The smallest additive submonoid of ℤ containing the k + 1 integers n + l·w + r_i: the set of all finite ℕ-linear combinations of them, 0 included. This is the semigroup ⟨n + λw + r_0, ..., n + λw + r_k⟩ of CLAIM.md, with λ written `l` because `λ` is reserved syntax. The carrier is ℤ rather than ℕ so that pseudo-Frobenius numbers and the differences h + p − f in the trace live in the same type as the semigroup. The definition does not impose the conditions on r; they are hypotheses of the record. For l ≥ 0 and the record's hypotheses every generator is positive (`Plan.arithmetic` gives 0 ≤ r_i and m = n + l·w > 0), and `Plan.numerical_and_pf_test` proves that the submonoid consists of nonnegative integers and contains every integer from some bound on (proved, not a record), so it is a numerical semigroup in the usual sense; PROOF.md Lemma 1(b) is the informal counterpart. For negative l the definition is still meaningful but the record never uses it there, since L ≥ 0.
- `pseudoFrobenius (H : Set ℤ) : Set ℤ := {x | x ∉ H ∧ ∀ h ∈ H, h ≠ 0 → x + h ∈ H}`. PF(H) as in PROOF.md §1: the non-elements x of H, taken in ℤ, with x + h ∈ H for every nonzero h ∈ H. PROOF.md §1 shows that for a numerical semigroup H ≠ ℕ every such x is positive (otherwise h = F(H) − x would give x + h = F(H) ∉ H), so this agrees with the textbook set PF(H) ⊆ ℕ \ H; for H = ℕ it gives {−1}, matching the convention F(ℕ) = −1. It is stated for an arbitrary set of integers; the record applies it only to H_λ.
- `trace (H : Set ℤ) : Set ℤ := {h | h ∈ H ∧ ∃ p ∈ pseudoFrobenius H, ∀ f ∈ pseudoFrobenius H, h + p - f ∈ H}`. Word for word the set tr(H) of CLAIM.md, with PF(H) as above and the arithmetic in ℤ (no truncated subtraction). It is the intended notion because it is the definition CLAIM.md gives, rendered literally.
- `traceResidue (H : Set ℤ) : ℕ∞ := (H \ trace H).encard`. res(H) = |H \ tr(H)| as an extended natural number: `Set.encard` is the cardinality of a finite set and ⊤ for an infinite one. `encard` is chosen over `Set.ncard` (which returns 0 for infinite sets) so that an equation `traceResidue H = N` with N : ℕ asserts that H \ tr(H) is finite and has exactly N elements; CLAIM.md's res(H) is a natural number, and the record recovers that by requiring the value to be some `N : ℕ`.
